# Create Mode Integration

This document maps the Create wizard to the CodeCompanion harness lifecycle and agent contracts.

## Agent Contracts Used

- **Researcher** (Steps 1-2): Collects project info, audience, tone
- **Planner** (Steps 3-5): Designs stages, confirms workflow

## Lifecycle Mapping

The Create wizard follows the first two harness stages:

1. **Task Definition** (Steps 1-2) → Project Info + Audience & Tone
2. **Agent Design** (Steps 3-5) → Stages + Review & Create

## Skill Reference

The wizard references `harness/skills/new-project/new-project.md` which defines:

- How to gather project requirements
- How to define agent roles and workflows
- How to structure the project for AI collaboration

This integration ensures users understand they are working within a structured, agent-driven process.
