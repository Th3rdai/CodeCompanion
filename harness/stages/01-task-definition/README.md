# Stage 1: Task Definition

## Purpose

Define the task, gather context, and establish scope before any design or implementation begins.

## Agents Involved

- **Researcher** — Gathers context from codebase and web
- **Planner** — Defines task scope, goals, and constraints

## Inputs

- User request or feature description
- Existing codebase context
- Research findings

## Outputs

- Task definition document (saved to `harness/plans/`)
- Scope statement
- Success criteria
- Constraints and assumptions

## Gate Criteria

- [ ] Task is clearly defined with measurable success criteria
- [ ] Scope is bounded (what's in/out)
- [ ] Research findings are documented
- [ ] No ambiguity in the goal

## Handoff

→ Stage 2: Agent Design (planner + reviewer)
