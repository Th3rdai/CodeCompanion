# Skill: New Project

## Purpose

Scaffold a new project with the harness structure, configs, and initial agent contracts.

## When to Apply

- User asks to create a new project
- User wants to set up a project with the harness framework

## Procedure

1. **Create directory** — Make the project directory
2. **Scaffold harness** — Create the `harness/` directory tree
3. **Write orientation** — Create CLAUDE.md, CONTEXT.md, FRAMEWORK.md
4. **Write agents** — Create the 5 agent contracts
5. **Write configs** — Create the 6 YAML config files
6. **Write skills** — Create skill stubs
7. **Write stages** — Create stage contracts
8. **Initialize git** — `git init` and initial commit
